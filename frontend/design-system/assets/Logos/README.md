# Logos

The product has no wordmark: the mark is drawn inline in `BrandMark` (`src/components/ui.tsx`) and the name is set in type beside it. These files are that drawing, exported.

- `brand-mark.svg`: the lens alone, two rings and four ticks, 2px round strokes. Single ink, written as `accent` light (#0a5e73); in code it takes `currentColor`.
- `brand-mark-tile.svg`: the mark as the app shows it, white lines on a 34px `accent` tile with `radius-mark` corners.
- `brand-mark-tile-large.svg`: the 52px sign-in version, `radius` corners.
