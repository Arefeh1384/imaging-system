# PageTitle

The page heading row: h1 and an optional muted subtitle, with actions at the other end. From `src/components/ui.tsx`.

- **Provide:** `title`; optionally `subtitle` (one sentence that explains what is recorded or why) and `children` (buttons, placed at the end and wrapping under on narrow screens).
- The title uses the `title` type style (1.7rem, 800). One per screen.
