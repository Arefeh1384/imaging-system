# BrandMark

The product mark: a lens of two rings and four ticks on an accent tile. From `src/components/ui.tsx`.

- **Provide:** nothing, or `large` for the 52px tile on sign-in pages (default 34px). It is `aria-hidden`; put the product name in text beside it.
- `accent` tile, `accent-ink` lines; `radius-mark` small, `radius` large.
- Beside it set «تصویربرداری و بیمه» in `.brand-name` and the panel in `.brand-sub`. The same drawing is in assets/Logos.
